# GRE 词卡

个人备考用的 GRE 单词闪卡,可安装到手机主屏幕离线使用。

## 用法

- 左滑 → 下一个词
- 右滑 → 上一个词
- 上滑 → 翻面看中文
- 点卡片 → 朗读英文(默认英音,可在书架页切换语音)
- 电脑上:方向键翻卡,空格发音

## 内容

9643 张卡片 / 482 个板块,按原书页码分组,页内乱序。等价词/同义词都拆成了独立卡片。

## 装到手机主屏幕

**iPhone**:Safari 打开网址 → 分享按钮 → 添加到主屏幕
**Android**:Chrome 打开网址 → 菜单 → 安装应用

装好后点图标直接全屏打开,断网也能背。

## 结构

```
index.html              主页面(PWA)
app.css / app.js        样式与逻辑
decks/*.js              词库数据,每本书一个文件
sw.js                   离线缓存
manifest.webmanifest    应用清单
```

词库由备考 PDF 提取而来,仅供个人学习使用。
