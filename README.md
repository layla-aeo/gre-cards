# 词卡

英语单词闪卡。滑动翻卡、真人发音、原书例句,可以装到手机主屏幕离线背。

### 打开就能用

**https://layla-aeo.github.io/gre-cards/**

不用下载、不用注册也能直接开始背。想在几台设备之间同步进度,再去注册账号。

## 收录的词书

| 词书 | 收词 | 分组方式 | 例句 |
|---|---|---|---|
| **GRE** | 9632 | 5 本原书,各按原书页码分页 | 8128 条 |
| **IELTS** | 4512 | 108 个场景板块(听力·租房场景·核心词…) | — |
| **CET-6** | 5511 | 111 组,每组 50 词 | — |
| **考研** | 6550 | 66 组,每组 100 词 | — |

每个板块内部都打乱了顺序,避免按字母表背时前后干扰。GRE 的等价词、同义词
都拆成了独立卡片,不是塞在一张卡的角落里。

GRE 例句取自原书,其中张巍镇考 3000 词那本的例句还带中文翻译。

## 怎么用

### 1. 选一本词书

底部导航切到「**词书**」→ 点一本 → 点「**添加为我的词汇**」。

之后「**词汇**」页就是这本书的内容。同一时间学一本,随时可以换,换书不会
丢掉已有进度。

GRE 点进去先选五本原书中的一本,再选页码;其余三本直接就是板块列表。

### 2. 背单词

进到板块里,正面只有单词和音标:

| 手势 | 作用 |
|---|---|
| **左滑** | 下一个词 |
| **右滑** | 上一个词 |
| **上滑** | 翻面看中文释义 |
| **点一下** | 朗读这个单词 |
| **长按** | 存进「常错词」,再长按取消 |

单词卡下面还有一张**例句卡**,默认不显示内容,点一下翻出例句原文和翻译。

电脑上可以用键盘:`←` `→` 翻卡,`↑` 看释义,`空格` 发音,`回车` 翻例句。

### 3. 常错词

背的时候长按卡片,那个词就进了「常错词」——它常驻在「词汇」页最上面。

点进去是一个列表,每条右边有 `×` 可以单独删掉,顶部有「背这些词」把它们
当成一个牌组来过。在常错词里背的时候,**长按就是移出**。

### 4. 发音

默认用**有道词典的英式真人录音**,重音清晰,不是机械合成音。拉不到的时候
自动回退到设备语音。

主页可以切换「真人录音 / 设备语音」。离线背词请切到设备语音。

> iPhone 上想让设备语音更自然:设置 → 辅助功能 → 朗读内容 → 声音 →
> 英语(英国) → 下载 Daniel 或 Serena 的「增强/高级」版本,回到主页选它。

## 装到手机主屏幕

装好之后点图标直接全屏打开,没有浏览器地址栏,**断网也能背**。

**iPhone / iPad**
1. 用 **Safari** 打开 https://layla-aeo.github.io/gre-cards/ (必须是 Safari,Chrome 不行)
2. 点底部中间的分享按钮 <kbd>↑</kbd>
3. 往下滑,选「**添加到主屏幕**」→ 添加

**Android**
1. 用 Chrome 打开同一个网址
2. 右上角菜单 ⋮ → 「**安装应用**」或「添加到主屏幕」

**电脑(Chrome / Edge)**
地址栏右侧会出现一个安装图标,点它即可。

## 账号与同步

不登录也能正常背,数据存在当前设备上。

想在手机和电脑之间同步,去「**主页**」用邮箱注册一个账号(密码至少 6 位),
在另一台设备登录同一个邮箱即可。词书选择、每个板块的进度、常错词都会跟过去。

**多个人可以同时用同一个网址**,各自注册各自的账号即可。不同账号的数据
互相独立,互相看不到——这一点由数据库的安全规则保证,每个账号只能读写
属于自己的那份记录。

## 想改成自己的版本

这是一个纯静态站点,没有后端服务器,Fork 之后开启 GitHub Pages 就能跑。

1. Fork 本仓库
2. 仓库 Settings → Pages → Source 选 `Deploy from a branch`,分支选 `main`,
   目录选 `/ (root)` → Save
3. 一两分钟后访问 `https://<你的用户名>.github.io/gre-cards/`

这样得到的副本**不带账号功能**(登录依赖仓库主人的 Firebase 项目),但背单词、
常错词、进度这些都照常工作,数据存在本机。

如果也想要账号同步,自己建一个免费的 Firebase 项目,开启「电子邮件/密码」
登录、建一个 Firestore 数据库,把下面的规则发布上去:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

再把项目的 Web 配置填进 `assets/config.js`,并在 Firebase 的
Authentication → Settings → 已授权网域里加上你的 `<用户名>.github.io`。

## 文件结构

```
index.html              页面骨架
manifest.webmanifest    应用清单(主屏幕图标、启动方式)
sw.js                   离线缓存;必须放在根目录,否则管不到整站
robots.txt              谢绝搜索引擎收录
assets/
  app.css               全部样式
  app.js                全部逻辑
  config.js             Firebase 前端配置
  icons/                主屏幕图标
books/
  index.js              词书目录
  gre.js                GRE 的五本原书清单
  gre.<原书>.js          某本原书的页码板块,点进那本才加载
  ielts.js  cet6.js  kaoyan.js
```

词库由公开的备考资料整理而来,仅供个人学习使用。
