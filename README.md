# 词卡

个人备考用的单词闪卡,可安装到手机主屏幕离线使用。

https://layla-aeo.github.io/gre-cards/

## 词书

| 词书 | 收词 | 板块 | 例句 |
|---|---|---|---|
| GRE | 9632 | 5 本原书 · 482 页 | 8128 |
| IELTS | 4512 | 108 个场景板块 | — |
| CET-6 | 5511 | 111 组 · 每组 50 词 | — |

GRE 保留五本原书各自的页码分组,点进书再点进页;IELTS 和 CET-6 直接进板块。
所有板块内部乱序,等价词/同义词都拆成了独立卡片。

## 用法

在「词书」里挑一本添加为自己的词汇,「词汇」页就显示这本书的内容。

- 左滑 → 下一个词
- 右滑 → 上一个词
- 上滑 → 翻面看中文
- 点单词卡 → 朗读(默认有道词典英式真人录音,离线时回退设备语音)
- 长按单词卡 → 存进「常错词」,再长按取消
- 点下方例句卡 → 翻出例句原文与翻译
- 电脑上:方向键翻卡,空格发音,回车翻例句

## 账号

主页可以用邮箱注册登录。不同账号的词汇、进度、常错词互相独立,
同一账号在多台设备之间自动同步。未登录时数据存在本机。

数据隔离由 Firestore 安全规则保证:每个账号只能读写 `users/<自己的 uid>`。

## 装到手机主屏幕

**iPhone**:Safari 打开网址 → 分享 → 添加到主屏幕
**Android**:Chrome 打开网址 → 菜单 → 安装应用

装好后点图标直接全屏打开,断网也能背。

## 结构

```
index.html              页面骨架(PWA)
app.css / app.js        样式与全部逻辑
config.js               Firebase 前端配置
books/index.js          词书目录
books/gre.js            GRE 的五本原书清单
books/gre.<原书>.js      某本原书的页码板块,点进去才加载
books/ielts.js
books/cet6.js
sw.js                   离线缓存(代码走网络优先,词库走缓存优先)
manifest.webmanifest    应用清单
```

词库由备考 PDF 提取而来,仅供个人学习使用。
